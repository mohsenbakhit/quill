# Quill

A lightweight, local-first screenwriting editor built with Tauri 2, React, and Tiptap. Write with Tab and Enter, save editable `.quill` documents, and export PDF or Fountain.

## Writing

- A quiet word processor layout with a US Letter paper canvas, Courier Prime 12 pt, a ruler, and 75–150% zoom.
- Scene navigation, live word/scene counts, current element, and unsaved status.
- Six structured elements: Scene heading, Action, Character, Dialogue, Parenthetical, and Transition.
- An element selector, undo/redo, contextual placeholders, and plain-text multiline paste.
- New, Open, Save, and Save as with native file dialogs. Save reuses the current path. New, Open, and window-close operations protect unsaved changes with Save / Discard / Cancel.

| Current element | Enter creates | Tab changes to | Shift+Tab changes to |
| --- | --- | --- | --- |
| Scene heading | Action | Action | Transition |
| Action | Action | Character | Scene heading |
| Character | Dialogue | Parenthetical | Action |
| Dialogue | Action | Parenthetical | Character |
| Parenthetical | Dialogue | Dialogue | Dialogue |
| Transition | Scene heading | Scene heading | Dialogue |

Use Cmd on macOS or Ctrl on Windows/Linux: `N` for New, `O` for Open, `S` for Save, `Shift+S` for Save as, `Z` for Undo, and `Shift+Z` for Redo. Scene headings, character cues, and transitions display/export in uppercase. Files retain your original text.

## Export

**PDF:** Generated by Rust with an embedded, OFL-licensed Courier Prime font, selectable/searchable text, Letter pages, 1.5-inch left and 1-inch right margins, screenplay indents, wrapping, pagination, and page numbers after the first page. Headings and character cues stay with following content where space permits. Long blocks can continue across pages. Characters missing from the bundled font produce an explicit error rather than a corrupt PDF; Fountain supports UTF-8 text.

**Fountain:** UTF-8 plain text following the [Fountain syntax](https://fountain.io/syntax/). Forced elements and escaped emphasis preserve screenplay structure and literal text. Dialogue/parentheticals require a preceding character cue; a character cue needs speech. Ambiguous literal note markers (`[[`), dialogue consisting of a parenthetical, and multiline headings/cues/parentheticals/transitions produce actionable errors. This avoids silently hiding or reclassifying your text. Consecutive dialogue paragraphs become one Fountain dialogue block with line breaks.

Export writes only to the path selected in the native save dialog. Cancellation writes nothing. Exporting does not mark the editable screenplay as saved.

The editor uses a continuous paper canvas; PDF pagination is calculated at export. Title pages, automatic continuation labels, live page breaks, autosave, Fountain import, FDX, and revision tracking are not implemented.

## Development

Install Node.js 22.12+ and the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) for your OS, including a current stable Rust toolchain.

```sh
npm ci
npm run tauri dev
```

`npm run dev` runs the browser preview at `http://localhost:1420`. Native open/save/export operations require the desktop app; browser preview displays a clear message when those operations are requested.

```sh
npm run build                 # TypeScript and production frontend
npm run tauri build           # Native application bundle
```

## Tests

```sh
npm test                      # React, actual Tiptap editor, file/export services
npm run test:watch            # Interactive frontend tests
npm run test:coverage         # HTML and LCOV reports in coverage/
npm run test:rust             # Validation, Fountain, PDF layout and decoding
npm run test:exports          # Real Rust output parsed independently by fountain-js
npm run test:all              # All three suites
npm run check:rust            # rustfmt and clippy with warnings denied
```

React tests use jsdom, Testing Library, and real ProseMirror editor instances; only the native Tauri boundary is mocked. They cover keyboard transitions, cursor splits, selection replacement, paste, schema serialization, undo/redo, navigation, zoom, file validation, asynchronous save races, cancellations, errors, menus, native close protection, and export command arguments/bytes.

Rust tests independently load generated PDFs with `lopdf`, verify page geometry and embedded fonts, extract Unicode text, and check that multipage output retains content. The export integration suite builds a small Rust executable and sends actual documents through it, then parses Fountain output with a separate implementation. CI runs checks on macOS, Windows, and Linux.

Generate a multipage export fixture for visual review:

```sh
cargo run --manifest-path src-tauri/Cargo.toml --example export_sample -- /tmp/quill-exports
```

Before a release, also run the desktop app: open a `.quill` file, edit with Tab/Enter, save/reopen it, export both formats through the native dialogs, inspect the PDF, and verify Cancel/Discard/Save on window close. The mocked UI suite cannot replace OS dialog and WebView smoke testing.

## Structure

- `src/App.tsx`, `src/components/`: writing interface and document workflows
- `src/extensions/`, `src/nodes/`: screenplay schema and keyboard behavior
- `src/lib/`: validation, saving, and Tauri export bridge
- `src-tauri/src/export.rs`: pure Rust Fountain/PDF exporters
- `src-tauri/src/export/tests.rs`: backend regression suite
- `scripts/export.integration.test.mjs`: cross-language export verification
- `public/fonts/`: bundled Courier Prime and its license
